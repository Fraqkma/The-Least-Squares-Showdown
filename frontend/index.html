Three ways to fit a model

OLS, Ridge, and Lasso

X holds the inputs, y holds the observed values, and β holds the numbers the model learns, including the intercept.

Ordinary least squares (OLS)

minβ ‖y − Xβ‖22

Choose coefficients that make the squared prediction errors as small as possible.

Ridge

minβ ‖y − Xβ‖22 + λ‖βnonintercept‖22

Square the coefficients to give larger ones a bigger penalty.

Lasso

minβ (1 / (2n))‖y − Xβ‖22 + α‖βnonintercept‖1

Penalize the absolute size of each coefficient. Some can shrink all the way to zero.

Ridge and Lasso leave the intercept out of the penalty. λ sets the penalty strength for Ridge, and α sets it for Lasso. The formulas put those strengths on different scales.

Show derivation

For Ridge, set the gradient to zero: (XTX + λP)β = XTy, with P = diag(0, 1, …, 1). The zero leaves the intercept unpenalized.

For a non-intercept Lasso coordinate j, let rj = y − Xβ + Xjβj, ρj = XjTrj/n, and zj = ‖Xj‖22/n. Then βj ← S(ρj, α)/zj, where S(t, α) = sign(t) max(|t| − α, 0). Update the intercept without thresholding.

Interactive 3D loss

Find the lowest loss

Each spot represents one possible line. The horizontal axes show its intercept and slope. Height shows how much loss that line gets. Drag to look from another angle.

Ordinary least squares (OLS) finds the line with the smallest sum of squared errors (SSE). Ridge adds a cost for a large slope and leaves the intercept out of the penalty.

Loading the objective.

With a design matrix A, least squares chooses coefficients w so that Aw is as close as possible to the observed vector y.

Least-squares objective minw ‖y − Aw‖22

The residual is perpendicular to every column of A, giving the normal equations:

ATAw = ATy

QR factorization and singular value decomposition (SVD) are two ways to break the matrix into simpler parts and solve for the coefficients.

See what the Ridge penalty changes

Ordinary least squares (OLS) and Ridge use the same degree and training points. Move λ to change the Ridge penalty. Try a high value and watch the curve and the validation mean squared error (MSE).

Loading validation errors.

Each pair shows the same coefficient for OLS and Ridge. The first pair is the intercept, the fitted value when all the model's features are zero. Ridge leaves it out of the penalty.

Unpenalized intercept‖y − Aw‖22 + λ ∑j>0 wj2

Ridge makes the coefficients smaller overall. When two features carry similar information, some individual coefficients can move differently. A very high λ can make the fitted curve too flat.

Battle A: regression models

Compare models on unseen observations

Predict how many bikes will be rented in each hour. Ordinary least squares (OLS), Ridge, and Lasso use the hour and whether it is a working day. We use root mean squared error (RMSE) on five validation windows to choose the settings.

Loading the recorded Bike Sharing result.

RMSE gives larger mistakes more weight. Mean absolute error (MAE) is the average size of a mistake. Both are in rentals per hour, and lower is better. The coefficient of determination (R²) compares predictions with guessing the average. Higher is better. The standard deviation of RMSE (RMSE SD) shows how much RMSE varies across validation windows.

What the benchmark numbers mean

Relative coefficient error tells you how far the answer is from the known coefficients. Residual norm combines the prediction gaps into one error measure. A larger condition number means the calculation is more sensitive to small changes. Input memory covers the matrix and target values. An iteration limit means gradient descent used all 10,000 steps before reaching its stopping goal.

Seed 42; shapes 100 × 8 and 500 × 16; condition numbers 10 and 10^6. Each method receives the same matrix and target within a case. Runtime is the median of three wall-clock repetitions. Gradient descent starts at zero and targets gradient norm 10^-8. Exploratory order excludes incomplete runs.
