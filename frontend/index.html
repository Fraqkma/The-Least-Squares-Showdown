Three ways to fit a model

Ordinary least squares (OLS), Ridge, and Lasso

X holds the inputs, y holds the observed values, and β holds the numbers the model learns, including the intercept.

Ordinary least squares (OLS)

minβ ‖y − Xβ‖22

Choose coefficients that make the sum of squared errors (SSE) as small as possible.

Ridge

minβ ‖y − Xβ‖22 + λ‖βnonintercept‖22

Add a squared penalty on non-intercept coefficients to pull large weights toward zero.

Lasso

minβ (1 / (2n))‖y − Xβ‖22 + α‖βnonintercept‖1

Penalize the absolute size of each non-intercept coefficient. Some can shrink all the way to zero.

Ridge and Lasso leave the intercept out of the penalty. λ sets the penalty strength for Ridge, and α sets it for Lasso. Because Lasso divides SSE by 2n, λ and α sit on different numerical scales.

Show derivation

For Ridge, set the gradient to zero: (XTX + λP)β = XTy, with P = diag(0, 1, …, 1). The zero leaves the intercept unpenalized.

For a non-intercept Lasso coordinate j, let rj = y − Xβ + Xjβj, ρj = XjTrj/n, and zj = ‖Xj‖22/n. Then βj ← S(ρj, α)/zj, where S(t, α) = sign(t) max(|t| − α, 0). Update the intercept without thresholding.

Writing the same design matrix as A and coefficient vector as w, least squares chooses w so that Aw is as close as possible to the observed vector y.

Least-squares objective minw ‖y − Aw‖22

The residual is perpendicular to every column of A, giving the normal equations:

ATAw = ATy

QR factorization (QR) and singular value decomposition (SVD) solve this system stably without explicitly inverting ATA.

Battle A: regression models

Compare models on unseen observations

Predict how many bikes will be rented per hour. Ordinary least squares (OLS), Ridge, and Lasso use the same 48-column design (hour of day, working-day status, and their interaction). Root mean squared error (RMSE) across five chronological development windows chooses each model's setting.

RMSE gives larger mistakes more weight. Mean absolute error (MAE) is the average mistake size. Both are measured in rentals per hour, where lower is better. The coefficient of determination (R²) compares predictions with guessing the mean (higher is better). Window RMSE standard deviation (RMSE SD) measures how much RMSE varies across the five chronological windows.

Benchmark setup and limits

Seed 42; matrix shapes 100 × 8 and 500 × 16; prescribed condition numbers 10 and 106 with noiseless y = Aβ. Every solver receives the exact same matrix and target within each case. Median runtime comes from three wall-clock repetitions on one machine and is descriptive rather than a universal speed rank. Batch Gradient Descent starts at zero, uses step 1 / ‖A‖22, targets gradient norm 10−8, and stops at 10,000 steps. Peak solver workspace memory is not measured here.
